# Tech Salary & Burnout Analysis Dashboard (2024)

## Project Overview
This project analyzes a synthetic dataset of tech professionals in 2024 to explore salary patterns and employee burnout trends across different job roles, work setups, and global locations. The goal was to generate actionable insights through data cleaning, exploratory data analysis (EDA), and interactive dashboard creation using Microsoft Excel.

The project includes two dashboards:
- **Salary Analysis Dashboard**
- **Burnout Analysis Dashboard**

---

## Dataset Description
The dataset contains **200 rows and 19 columns**, representing tech professionals across various industries and locations.

Key columns include:
- Job Title
- Company Location
- Work Setup (Remote / Hybrid / On-site)
- Years of Experience
- Salary (USD)
- Weekly Hours Worked
- Meetings per Day
- Days Since Last Vacation
- Mental Fatigue Score
- Burnout Rate
- Job Satisfaction Score
- Burnout Level (Calculated column)

 *Note: This dataset is synthetic and was generated for practice purposes.*

## Data Cleaning Process
The following cleaning steps were performed:
- Checked for missing values in key columns.
- Ensured numeric columns (Salary, Burnout Rate, Weekly Hours) were correctly formatted.
- Grouped continuous variables such as Weekly Hours and Years of Experience for better analysis.
- Identified extreme outliers and ensured insights were not misleading due to small sample size categories.
- Removed duplicates.
- Formatted columns like the salary into currency.

# Salary Dashboard Analysis

## KPIs Displayed
- Average Salary
- Median Salary
- Maximum Salary
- Minimum Salary
- Highest Paying Role

## Key Visuals Included
- Salary by Job Role
- Salary by Years of Experience
- Salary by Work Setup
- Salary by Gender
- Salary by Job Location

## Key Insights
- Cloud Architects earn the highest average salary among all job roles.
- Salary increases steadily with years of experience, with a noticeable rise after 5 years.
- Bangalore has the highest average salary compared to other job locations.
- On-site workers earn higher salaries on average compared to remote and hybrid workers.
- Non-Binary employees show the highest average salary, though sample size should be considered.

#  Burnout Dashboard Analysis

## KPIs Displayed
- Average Burnout Rate
- Highest Burnout Rate
- Average Job Satisfaction
- High Burnout Employee Count
- Total Number of Employees

## Key Visuals Included
- Burnout by Weekly Hours
- Burnout by Days Since Last Vacation
- Burnout by Daily Meetings
- Burnout by Job Roles
- Burnout by Work Setup
- Burnout vs Job Satisfaction (Scatter Plot)

## Key Insights
- DevOps Engineers show the highest burnout rate among job roles.
- Burnout increases as the number of days since last vacation increases.
- Employees with more than 6 meetings per day report higher burnout rates.
- On-site employees experience higher burnout compared to remote and hybrid workers.
- Job satisfaction decreases as burnout increases, showing a strong negative relationship.
- Most employees work between 35–54 hours per week, representing the dominant working range.

---

##  Recommendations
Based on the analysis, the following recommendations are suggested:
- Companies should encourage regular vacations and time off to reduce burnout.
- Limiting unnecessary daily meetings may help reduce employee fatigue and burnout.
- Hybrid and remote work setups may reduce burnout compared to on-site roles.
- HR teams should monitor high-risk roles (e.g., DevOps Engineers) and implement wellness programs.
